# Telegram: бот, мини-приложение и доступ по чату

Приложение можно открыть из Telegram или как обычный сайт. Тот, кто вошёл,
получает свою библиотеку колод на сервере. Контур участников образуют два
заранее определённых чата — «Важное» и «Флуд», а не любой чат, куда добавили
бота. Ниже — что настроить, чтобы это заработало.

## 1. Бот

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте
   имя и адрес бота.
2. Скопируйте токен и положите его в `backend/.env`:

   ```
   TELEGRAM_BOT_TOKEN=1234567890:AA...
   SESSION_SECRET=<node -e "console.log(require('crypto').randomBytes(32).toString('hex'))">
   ```

Пока `TELEGRAM_BOT_TOKEN` пуст, сервер работает в режиме разработки: пускает по
имени и никого не проверяет. Как только токен появился, вход только через
Telegram, а `/auth/dev` отвечает отказом.

## 2. Мини-приложение

Мини-приложение — это фронт, открытый внутри Telegram, поэтому ему нужен
публичный адрес по HTTPS.

1. `/newapp` у @BotFather → выберите бота, задайте короткое имя и URL фронта.
2. BotFather вернёт ссылку вида `https://t.me/имя_бота/короткое_имя`.
   Её и кладём в `backend/.env`:

   ```
   MINI_APP_URL=https://t.me/имя_бота/короткое_имя
   ```

Именно ссылка `t.me/бот/приложение` умеет открываться из группы — обычный
адрес сайта Telegram откроет во внешнем браузере, где нет подписи входа.

Локально публичный адрес проще всего получить туннелем:

```bash
npm run dev                       # фронт на 5173
npm run dev:backend               # сервер на 3000
cloudflared tunnel --url http://localhost:5173
```

Адрес туннеля укажите в BotFather, а фронту скажите, где сервер:

```
# .env в корне
VITE_BACKEND_URL=https://<туннель-до-сервера>
VITE_PUBLIC_URL=https://<туннель-до-фронта>
```

Сервер тоже должен быть виден снаружи — мини-приложение обращается к нему из
телефона, а не с вашей машины. Его адрес добавьте в `FRONTEND_ORIGIN`, чтобы
CORS не отбил запросы.

## 3. Доступ и реестр по двум чатам

ID «Важного» и «Флуда» задаются в `TELEGRAM_ALLOWED_CHAT_IDS`. При добавлении
бот не должен отправлять автоматическое приветствие. Произвольные новые чаты
не включаются в экосистему автоматически.

Полный первоначальный список загружается из Telegram CSV: Bot API не умеет
выдать всех уже состоящих в обычной группе участников. После импорта бот
поддерживает членство через обновления `chat_member` о вступлении и выходе.
Членство в каждом из двух чатов хранится отдельно.

Команды бота:

| Команда | Где | Что делает |
| --- | --- | --- |
| `/start`, `/app` | личка, чат | присылает ссылку на приложение |
| `/id` | где угодно | показывает идентификатор чата |

Как проверяется доступ:

1. Мини-приложение отдаёт серверу `initData` — подписанные Telegram данные о
   том, кто открыл приложение.
2. Сервер проверяет подпись ключом бота: подменить пользователя нельзя.
3. Затем спрашивает у Telegram `getChatMember` по каждому разрешённому чату.
   Есть участие хотя бы в одном — выдаётся сессия на 12 часов.
4. Ответ Telegram кэшируется на 5 минут, поэтому исключённый из чата теряет
   доступ в течение этого времени (сессия при этом доживает свой срок).

Для надёжного получения `chat_member` updates и статистики сообщений/реакций
боту нужны подходящие права, а Privacy Mode следует отключить через BotFather.
Пропущенную историю Telegram задним числом не отдаёт.

Разрешённые чаты и корневые администраторы:

```
TELEGRAM_ALLOWED_CHAT_IDS=-100111,-100222  # только «Важное» и «Флуд»
TELEGRAM_ADMIN_IDS=12345678                # личный доступ мимо чатов
```

## 4. Ссылки прямо на экран

Параметр `startapp` открывает нужную страницу сразу:

| Ссылка | Экран |
| --- | --- |
| `t.me/бот/приложение?startapp=quiz_ABCD` | стол капитана комнаты `ABCD` |
| `t.me/бот/приложение?startapp=board_ABCD` | проектор комнаты |
| `t.me/бот/приложение?startapp=host_ABCD_KEY7` | пульт ведущего |
| `t.me/бот/приложение?startapp=roulette` | колесо удачи |

Разбор параметра живёт в [`src/utils/startParam.ts`](../src/utils/startParam.ts).

## 5. Что где лежит

| Файл | Содержимое |
| --- | --- |
| PostgreSQL `decks` | колоды, публикация и доступ по коду |
| PostgreSQL `participants`, `participant_chats` | профили и членство в двух чатах |
| PostgreSQL `activity_daily` | сообщения, реакции и дневная активность |
| `backend/data/` | мероприятия и надёжность до их миграции в PostgreSQL |
| `backend/uploads/` | изображения, аудио и видео из колод |

Каталоги задаются переменными `DATA_DIR` и `MEDIA_DIR`. JSON-записи атомарные:
файл пишется рядом и переименовывается. PostgreSQL, `data` и `uploads` должны
резервироваться независимо.

## 6. Два процесса с одним ботом

Обновления бота Telegram отдаёт только одному получателю. Если рядом крутится
второй сервер с тем же токеном — выключите у него опрос:

```
TELEGRAM_POLLING=0
```

Проверка доступа и вход при этом продолжают работать: они ходят в Telegram
сами, а не через очередь обновлений.

Если хостинг не может напрямую обратиться к `api.telegram.org`, задайте
HTTP(S)- или SOCKS5-прокси только для бота:

```
TELEGRAM_PROXY_URL=http://user:password@proxy.example.com:3128
# либо socks5://user:password@proxy.example.com:1080
```

Вход, проверка членства и polling пойдут через него; остальной трафик сервера
останется прямым. Адрес прокси не выводится в логи.

## 7. Разработка без Telegram

Оставьте `TELEGRAM_BOT_TOKEN` пустым — на экране входа появится поле «Как вас
зовут». Имя превращается в постоянный идентификатор, так что колоды остаются
за вами между запусками. На сервере с ботом этот вход закрыт; включить его
принудительно можно переменной `ALLOW_DEV_AUTH=1`.

## 8. Вход с обычного сайта

Если приложение открыли не как Mini App, на экране входа показывается
официальная кнопка Telegram Login. Она возвращает подписанные данные
пользователя; сервер проверяет подпись тем же токеном бота, проверяет участие
в разрешённом чате и выдаёт обычную сессию приложения.

Для production-домена откройте @BotFather, выберите бота → **Bot Settings** →
**Domain** (либо используйте `/setdomain`) и привяжите домен сайта. Без этого
Telegram Login Widget откажется авторизовывать пользователей. Кнопка также
запрашивает разрешение боту отправлять личные сообщения — оно понадобится для
напоминаний о мероприятиях.
